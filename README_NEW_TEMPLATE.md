# 🎓 Academic IPR Initiative Website
## CHRIST (Deemed to be University) - Lavasa Campus, Pune

### 📋 Project Overview
Professional academic website showcasing research on **"Protection of Indigenous Culture & Products through Intellectual Property Rights (IPR)"** with focus on the Maasai community.

**Institution:** CHRIST (Deemed to be University)

## 📐 Website Structure

### 1️⃣ **Hero Section**
- Full-width 4K Maasai community background image
- Academic badges (IPR Awareness, Community Ownership, Research Initiative)
- Strong institutional messaging
- Dual CTA buttons

### 2️⃣ **About the Initiative**
- Explanation of IPR concepts
- Importance for indigenous communities
- Global challenges with cultural misappropriation
- Three-card layout with icons

### 3️⃣ **Problem Statement** (Timeline Layout)
- Four major challenges presented chronologically
- Each with: Problem | Example | IPR Solution
- Visual timeline with numbered icons
- Research-oriented presentation

### 4️⃣ **IPR Framework** (Core Learning)
- Five types of IP protection:
  - Trademark
  - Geographical Indication (GI)
  - Design Rights
  - Copyright
  - Patent
- Each includes: Definition | Maasai Example | Ownership Model

### 5️⃣ **Product Matrix**
- Visual grid showcasing 6 Maasai products:
  - Beadwork & Jewelry
  - Shúkà Cloth
  - Herbal Knowledge
  - Cultural Tourism
  - Performances
  - **Enkare Water** (Featured Case Study)
- Each shows applicable IPR, ownership model, and protection status

### 6️⃣ **Case Study: Enkare Water**
- Detailed storytelling layout
- Meaning of "Enkare"
- 5-step trademark process
- Impact metrics with icons
- Community cooperative model

### 7️⃣ **Community Ownership (Enkop)**
- Stakeholder diagram (Elders, Women, Youth, Cooperative)
- Benefit-sharing flow chart
- Distribution percentages
- Governance structure

### 8️⃣ **Legal Framework**
- Kenyan IPR laws
- International treaties (TRIPS, WIPO, Nagoya Protocol)
- Academic explanation style
- Importance of global protection

### 9️⃣ **Learning Resources**
- Downloadable presentation
- Research papers
- External links (KIPI, WIPO)
- Video tutorials
- Community testimonials

### 🔟 **Academic Footer**
- CHRIST University logo & information
- Quick links navigation
- Resources & Legal links
- **Academic Disclaimer Box**
- Copyright & attribution

```css

/* Neutrals */
--white: #FFFFFF

--charcoal: #2B2725

/* IPR Type Colors */
--color-trademark: #E74C3C   /* Red */

--color-design: #9B59B6       /* Purple */
--color-copyright: #F39C12    /* Orange */
--color-patent: #1ABC9C       /* Green */
```

### Typography
- **Headings:** Merriweather (Elegant Serif)
- **Body:** Inter (Modern Sans-Serif)
- Responsive font scaling with `clamp()`

### Spacing
- Section Padding: 100px (desktop), 70px (tablet), 50px (mobile)
- Container Max-Width: 1200px
- Consistent gaps: 25-40px
